# **Projeto DaRoça** 🍊
Repositório para aula de Praticas Profissionais, do curso de Desenvolvimento de Sistemas.

O Da Roça é um sistema web desenvolvido ao longo de cinco meses durante o curso técnico de Desenvolvimento de Sistemas. O projeto tem como objetivo facilitar a logística de entrega de produtos agrícolas, conectando produtores locais a clientes de forma prática, rápida e organizada.

Construído com o apoio de ferramentas como Figma e Trello, tal quanto o uso das linguagens e bibliotecas Node.js, JavaScript, HTML e CSS, o site oferece uma interface simples e intuitiva, permitindo que os usuários façam pedidos, visualizem produtos e acompanhem o andamento das entregas. No back-end, o sistema realiza o gerenciamento das rotas e pedidos, garantindo praticidade ao produtor e uma experiência eficiente ao cliente.

O projeto destaca-se pelo foco na organização das rotas de entrega, tornando o processo mais ágil e reduzindo deslocamentos desnecessários, além de apresentar um design limpo e responsivo.

Este trabalho representa a união entre aprendizado técnico e solução de um problema real, integrando lógica de programação, banco de dados, interface web e boas práticas de desenvolvimento.
